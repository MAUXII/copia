# The Copia contract

What every component in this repository must satisfy. `npm run check`
enforces the mechanical parts and prints the file, the rule and the fix.

## Files

```
registry/<slug>/
  <slug>.tsx     the component, one file
  demo.tsx       ~5 s of motion under the preview recorder's cursor path
  meta.json      metadata (below)
public/previews/<slug>.webp   generated by npm run preview
public/previews/<slug>.mp4    generated by npm run preview (1280x800, 3–8 s, no audio)
knowledge/case-studies/<slug>.md   how it was copied (not checked, but expected)
```

- `slug`: kebab-case, unique, same as the folder name.
- Imports: `react`, `motion`, `motion/react`, `lucide-react`, `@/lib/utils`;
  `demo.tsx` may also import `./<slug>`. Every npm package used must be listed
  in `meta.json` → `dependencies` (`react` excluded).

## meta.json

```json
{
  "slug": "progressive-blur",
  "name": "Progressive Blur",
  "description": "One sentence, including what Copia added.",
  "category": "effects",
  "tags": ["blur", "ios"],
  "author": { "name": "Your name", "github": "your-user" },
  "inspiration": { "author": "Original creator", "url": "https://original" },
  "dependencies": [],
  "props": [{ "name": "layers", "type": "number", "default": "8", "description": "…" }],
  "createdAt": "2026-10-18"
}
```

Categories: `buttons`, `text`, `cards`, `navigation`, `effects`. Use
`{ "author": "original", "url": null }` only for genuinely new work.

## Code

- TypeScript, typed props with defaults, `className` merged with `cn()`.
- Colors through theme CSS variables (`bg-background`, `text-foreground`,
  `var(--border)` …). No hard-coded palette unless it is the point of the
  effect and overridable by a prop.
- Interactive components work with the keyboard.
- Respect `prefers-reduced-motion` (`useReducedMotion()` from Motion, or the
  media query).
- `"use client"` only when the component uses state, effects or events.
