# The Copia contract

What every component in this repository must satisfy. `npm run check`
enforces the mechanical parts and prints the file, the rule and the fix.

## Files

```
registry/<slug>/
  <slug>.tsx     the component, one file
  demo.tsx       ~5 s of motion under the preview recorder's cursor path
  meta.json      metadata (below)
public/previews/<slug>.webp          generated by npm run preview (dark)
public/previews/<slug>.mp4           generated by npm run preview (dark, 1280x800, 3–8 s, no audio)
public/previews/<slug>-light.webp    generated by npm run preview (light)
public/previews/<slug>-light.mp4     generated by npm run preview (light, same rules)
knowledge/case-studies/<slug>.md   how it was copied (not checked, but expected)
public/demo/<slug>/*               demo images, each credited in meta.json → assets
```

- `slug`: kebab-case, unique, same as the folder name.
- Imports: `react`, `motion`, `motion/react`, `lucide-react`, `@/lib/utils`,
  and `three` / `gsap` for WebGL pieces;
  `demo.tsx` may also import `./<slug>`. Every npm package used must be listed
  in `meta.json` → `dependencies` (`react` excluded).

## meta.json

```json
{
  "slug": "progressive-blur",
  "name": "Progressive Blur",
  "description": "One sentence, including what Copia added.",
  "category": "effects",
  "tags": ["blur", "ios"],
  "author": { "name": "Your name", "github": "your-user" },
  "inspiration": { "author": "Original creator", "url": "https://original" },
  "credits": [{ "author": "Secondary credit (optional)", "url": "https://…" }],
  "assets": [{ "file": "photo.webp", "author": "creator", "source": "https://www.lummi.ai/photo/…", "license": "Lummi License" }],
  "dependencies": [],
  "props": [{ "name": "layers", "type": "number", "default": "8", "description": "…" }],
  "controls": [
    { "prop": "layers", "type": "number", "min": 2, "max": 16, "step": 1, "default": 8 },
    { "prop": "tint", "type": "boolean", "default": false },
    { "prop": "curve", "type": "select", "options": ["linear", "exponential"], "default": "exponential" }
  ],
  "createdAt": "2026-10-18"
}
```

`controls` power the viewer's Props Customizer (sliders, switches, options,
generated JSX). List the props worth tweaking live; `default` must match what
the demo shows. The demo's default export receives them as props and spreads
them onto the component:

```tsx
export default function Demo(props: Pick<ProgressiveBlurProps, "layers" | "tint" | "curve">) {
  return <ProgressiveBlur {...props} direction="bottom" />
}
```

Categories: `buttons`, `text`, `cards`, `navigation`, `effects`. Use
`{ "author": "original", "url": null }` only for genuinely new work.

## Code

- TypeScript, typed props with defaults, `className` merged with `cn()`.
- Every colour the component uses is a prop, defaulting to the reference's
  colour, with a `{ "type": "color", "default": "#rrggbb" }` control; no
  hard-coded colour classes (`bg-[#...]`), which `npm run check` rejects.
- Light and dark: switching the viewer's theme must turn every surface
  (background, text, borders, pills); no fixed page colours like `bg-white`
  or `text-black` in the component or the demo.
- Colors through theme CSS variables (`bg-background`, `text-foreground`,
  `var(--border)` …). No hard-coded palette unless it is the point of the
  effect and overridable by a prop.
- Interactive components work with the keyboard.
- Respect `prefers-reduced-motion` (`useReducedMotion()` from Motion, or the
  media query).
- `"use client"` only when the component uses state, effects or events.
